============================================
  Piper TTS 語音合成工具 — 使用說明書
============================================

本工具為 Piper TTS 的 Web 圖形界面，無需命令列操作，
打開瀏覽器即可將文字轉換為自然語音。

============================================
  一、啟動程式
============================================

1. 打開「命令提示字元」或「Windows PowerShell」

2. 切換到程式目錄：
   cd 此資料夾所在路徑

3. 安裝依賴（僅首次）：
   pip install piper-tts gradio numpy requests

4. 啟動服務：
   python app.py

5. 看到類似以下提示後，打開瀏覽器：
   Running on local URL:  http://127.0.0.1:7860

6. 在瀏覽器地址欄輸入 http://127.0.0.1:7860 並回車
   即可看到操作界面。


============================================
  二、界面介紹
============================================

界面分為上下兩個區域：

【上部】操作區（左）與輸出區（右）
  - 模型選擇：下拉選取已安裝的語音模型
  - 混合語言模式：中英混輸時自動分段，用不同模型合成（見第三章）
  - 文本輸入：輸入或粘貼要合成語音的文字
  - 文件上傳：可直接上傳 .txt 文本文件
  - 語音參數：調整語速、音量等（可折疊）
  - 生成按鈕：點擊開始合成語音
  - 音頻播放器：播放生成的語音，也可下載保存

【下部】模型管理區
  - 模型庫：瀏覽 HuggingFace 上的可用模型
  - 下載進度：查看正在下載的模型進度
  - 已安裝模型：查看與刪除已安裝的模型


============================================
  三、混合語言模式（中英混輸）
============================================

當文本同時包含中文（或日文/韓文）和英文時，
可使用混合語言模式自動分段，分別用不同語音模型合成後拼接。

操作步驟：
1. 勾選「啟用混合語言模式」核取方塊
2. 在「中文段落使用模型」下拉框中選取一個 CJK 模型
   （如 zh_CN-huayan-medium）
3. 在「英文段落使用模型」下拉框中選取一個拉丁語言模型
   （如 en_US-lessac-medium）
4. 在文本框中輸入混合文本，例如：
     這是利用 piper TTS 生成的中文語音測試。
5. 點擊「生成語音」

分段規則：
- 漢字、假名、諺文、CJK 標點符號 → CJK 模型
- 英文、數字、ASCII 標點 → Latin 模型
- 全形標點（，。！？：；等）會自動歸入 CJK 段落

注意事項：
- 至少需要各安裝一個 CJK 和 Latin 模型
- 若文本只有純中文或純英文，會提示無法使用混合模式
- 段落之間會自動插入靜音間隙，避免音頻拼接爆音


============================================
  四、下載語音模型（首次使用必做）
============================================

模型是語音合成的「聲帶」，不同模型對應不同語言和音色。

操作步驟：
1. 在下方「模型庫」表格中找到想要的模型
   - 可用「搜尋模型」輸入關鍵字，如 "zh_CN" 或 "lessac"
   - 也可用「語言」下拉框快速過濾

2. 常用中文模型推薦：
   - zh_CN-huayan-x_low    體積最小(19.7MB)，適合快速試用
   - zh_CN-huayan-medium   中等體積(60.3MB)，品質較好
   - zh_CN-xiao_ya-medium  女聲，中等體積(60.3MB)

3. 常用英文模型推薦：
   - en_US-lessac-medium   女聲，中等體積(60.3MB)
   - en_US-ryan-medium     男聲，中等體積(60.3MB)

4. 將模型名稱複製到「輸入要下載的模型名稱」框中，
   點擊「下載模型」按鈕
   下載完成後會顯示提示，模型自動出現在「已安裝模型」列表中

5. 在「選擇已安裝模型」下拉框中選取要使用的模型


============================================
  五、輸入文本
============================================

有三種方式輸入文本：

方式一：直接輸入
  在「輸入文本」文字框中直接輸入或粘貼要合成語音的內容。

方式二：上傳 TXT 文件
  點擊「上傳 TXT 文件」區域，選擇電腦上的 .txt 文件，
  文件內容會自動填入文本框，上傳後仍可手動修改。

方式三：混合使用
  先上傳 TXT 文件，再手動編輯修改文本內容。


============================================
  六、調整語音參數
============================================

點擊「語音參數」展開設置面板（預設折疊，一般不需調整）：

  語速：數值越大越快
    1.0 = 正常速度
    0.5 = 半速（慢一倍）
    2.0 = 雙倍速

  音量：數值越大越響
    1.0 = 原始音量
    0.5 = 減半
    1.5 = 增強

  韻律變化：控制語調的高低起伏
    預設 0.667，數值越大起伏越大

  音素變化：控制發音的變化程度
    預設 0.8，一般不需調整

新手建議：保持預設值即可，直接點擊生成。


============================================
  七、生成語音
============================================

1. 確認已選擇模型（或已設定混合模式）
2. 確認已輸入文本
3. 點擊「生成語音」按鈕
4. 等待幾秒（視文本長度而定）
5. 右側出現音頻播放器，點擊播放試聽
6. 點擊播放器右上角的下載圖標，可保存為 .wav 文件


============================================
  八、管理模型
============================================

刪除模型：
  在「已安裝模型」下拉框中選取要刪除的模型，
  點擊「刪除模型」即可。

  注意：刪除後如需再次使用，需重新下載。

查看模型訊息：
  下載完成後會顯示模型大小（如 60.3MB）。


============================================
  九、遷移到其他電腦
============================================

本程式無硬編碼路徑，所有模型存放在程式目錄下的 models/
資料夾中，可直接遷移。

遷移步驟：
1. 將整個程式資料夾複製到移動硬碟或新電腦
2. 在新電腦上安裝 Python（建議 3.10 以上）
3. 安裝依賴套件：
   pip install piper-tts gradio numpy requests
4. 切換到程式目錄，執行 python app.py 即可

注意：
- models/ 資料夾中的 .onnx 模型文件體積較大（每個約 20-60MB），
  複製時可能需要一些時間
- 如果新電腦無法訪問 HuggingFace（網路限制），
  可將整個 models/ 資料夾一併複製，無需重新下載
- 不同作業系統均可使用（Windows / macOS / Linux），
  只要 Python 和依賴套件安裝正確即可


============================================
  十、關閉程式
============================================

1. 關閉瀏覽器頁面
2. 回到命令提示字元窗口，按 Ctrl + C 停止服務

下次使用時重複「一、啟動程式」的步驟即可。


============================================
  十一、常見問題
============================================

Q: 生成失敗，提示「找不到模型」？
A: 請先下載模型。在「模型庫」中找到模型並點擊下載，
   下載完成後在模型下拉框中選取。

Q: 下載模型失敗？
A: 檢查網路連接是否正常，模型文件託管在 HuggingFace，
   可能需要穩定的網路環境。

Q: 生成的語音聽起來不自然？
A: 可嘗試調整「韻律變化」參數（0.5-1.0 之間嘗試）。
   不同模型的自然度也有差異，可多試幾個模型。

Q: 生成較慢？
A: Piper 在 CPU 上運行，長文本需要更多時間。
   一般每秒可生成約 15-20 字的語音。

Q: 中文模型生成效果如何？
A: Piper 的中文支援為社區貢獻，效果因模型而異。
   huayan 系列是較成熟的選擇。

Q: 混合模式下標點符號歸屬不對？
A: 全形標點（，。！？等）會自動分配給 CJK 模型，
   半形標點（, . ! ?等）會分配給 Latin 模型。
   如果仍有問題，請檢查標點是否為全形字符。

Q: 端口 7860 被佔用？
A: 修改 app.py 最後一行中的 server_port 數值，
   如改為 server_port=7861。

Q: 遷移後無法執行？
A: 確認已安裝 Python，並執行 pip install piper-tts gradio numpy requests。
   若 piper-tts 安裝失敗，可嘗試 pip install piper。


============================================
  十二、快捷技巧
============================================

- TXT 文件拖放到瀏覽器上傳區域即可快速加載
- 生成後的音頻可直接拖放播放器進度條選取片段試聽
- 右鍵點擊音頻播放器的三點菜單可調整播放速度
- 多個模型可同時保留，根據場景切換使用
- 英文模型也可朗讀中文拼音（效果不如中文專用模型）
- 混合語言模式適用於任意 CJK（中日韓）+ 拉丁語言的組合
